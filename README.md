# FM-IT Chords

Аккорды и текст любой песни по ссылке YouTube — программа для Windows 10/11.

**[⬇ Скачать последнюю версию](https://github.com/fmitsamarkand/fmit-chords-releases/releases/latest)**

- Распознавание аккордов по каждой доле, схемы для гитары и пианино
- Текст песни с аккордами над словами, режим «Фокус» и караоке
- Клип YouTube прямо в программе
- Тюнер для гитары, распознавание слов нейросетью Whisper
- Интерфейс: русский, узбекский (алфавит 2026), английский
- Программа сама проверяет обновления и устанавливает новые версии

Здесь публикуются только установщики. Создатель: **Фирдавс Шухратович**, учебный центр FM-IT, Самарканд.
